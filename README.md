# المليونير السوري

لعبة مسابقات ثقافية باللغة العربية، مبنية باستخدام Flutter لنظام Android.

## تشغيل المشروع
```bash
flutter pub get
flutter run
```

## الفحوصات وبناء APK
```bash
flutter analyze
flutter test
flutter build apk --release
```

ملف APK الناتج:
`build/app/outputs/flutter-apk/app-release.apk`

## محتويات النسخة الحالية
- 15 سؤالاً متدرجاً بأربعة خيارات.
- سلم جوائز يصل إلى مليون.
- مؤقت 30 ثانية لكل سؤال.
- وسائل مساعدة: 50:50، تصويت الجمهور، والاتصال بصديق.
- الانسحاب وإعادة اللعب.
